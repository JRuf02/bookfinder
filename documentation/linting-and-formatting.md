# Linters, formatters and other language-specific tools used in this project

All formatters, linters and import sorting are set up to auto-run on save if the project is opened in a vscode devcontainer.

Alternatively, the most important tools can also be run from the terminal, via make.

## Make

Run `make help` in the root directory to get an overview.
